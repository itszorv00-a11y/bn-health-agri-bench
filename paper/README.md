# Paper skeleton

Compile: `make paper` (requires a TeX distribution with pdflatex + bibtex;
not installed in this sandbox). English-only for now; if Bangla excerpts are
needed, switch to XeLaTeX + a Bangla font (Noto Sans Bengali).

Every `\todo{...}` marks content that must come from actual data, IAA output,
or screenshots of committed analysis artifacts. Do not delete a TODO without
replacing it with a real, traceable result.
